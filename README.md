## 🧠 Conceptual Deep Dive — How the Network Breathes

To use a tool well, you should understand its rhythm. The anonymity network this project accompanies functions like a relay race where each runner knows only the handoff, never the whole course.

1. **Your Request Enters the Race** — The browser encrypts your destination in layers, like envelopes inside envelopes.
2. **The First Relay Peels a Layer** — It knows only the next runner, never you.
3. **The Middle Relay Peels Another** — It knows neither where you started nor where you will end.
4. **The Exit Relay Delivers** — It speaks to the destination on your behalf, unaware of your origin.
5. **The Return Path Retraces Steps** — Responses travel back through the same chain in reverse.

This layered design is why we speak of **onion routing** — each layer of encryption must be peeled to progress, but no single relay ever sees the full picture.

## 🛠️ Troubleshooting Atlas

Troubleshooting is detective work with a compass. Below are the most common trails and the direction to travel.

### 🔌 Connection Refused or Stalled

- Confirm that your system clock is accurate; even a few minutes of drift can disrupt secure handshakes.
- Try a different network — school, workplace, and public hotspots often restrict unusual traffic.
- Consider enabling a bridge relay (see the next section).

### 🌉 Bridge Relay Assistance

Bridges are unlisted entry points that help when the standard path is blocked. To use one:

1. Open the connection settings inside the browser.
2. Choose the option to use a provided bridge.
3. Select a bridge type — obfs4, snowflake, or meek — based on what works in your region.
4. Save and reconnect.

### 🐢 Slow Performance

- Latency is inherent to multi-hop routing; three relays means three times the distance.
- Close unused tabs — memory pressure affects every browser.
- Avoid streaming high-bandwidth media if anonymity matters more than speed.

### 🔐 Site Won't Load Properly

- Some sites block known exit relays intentionally.
- Try requesting a new circuit — this changes your exit path.
- The Safest security level disables scripts that many modern sites require; drop to Safer if functionality is essential.
